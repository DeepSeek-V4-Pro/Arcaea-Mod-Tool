# iOS 实验模式（实验性功能）

> 本文面向想用 arcaea-mod-tool 修改 iOS 版 Arcaea 的用户。
> ⚠️ **实验性功能**：只做「提取素材 → 替换素材 → 重打包」三段，**原包与签名均需自行处理**。
> 改包安装可能违反游戏服务条款，有封号风险，请先阅读 [免责声明与注意事项](免责声明与注意事项.md)。

---

## 一、原理（一句话）

**IPA 本质就是 zip。** iOS 版 Arcaea 的素材树位于 `Payload/Arc-mobile.app/` 下，
与 Android 版 `assets/` 下的内容**逐字节同构**（实测 4417 个共有路径、4122 个完全一致），
因此扫描、分类、替换、重打包可以 100% 复用现有引擎——只需把素材根从
`assets/` 换成 `Payload/<App>.app/`。

与 Android 流程仅有两处不同，均为平台硬门槛，工具不做、也做不了：

| 环节 | Android（正式功能） | iOS（实验性） |
|---|---|---|
| 原包获取 | App Store 直装即 zip | **必须越狱 dump 解密**（官方包带 FairPlay DRM） |
| 签名安装 | 内置 APK v2 自签 | **必须 Apple 签名链**（Sideloadly / 爱思助手，免费 ID 7 天） |

## 二、准备工作（原包自备）

官方 App Store 分发的 Arcaea 主程序是 **FairPlay 加密**的，直接改、重打包毫无意义。
需要先在越狱设备上 dump 出解密版（社区标准流程，工具本身不含此功能）：

```
TrollInstallerX（CoreTrust 漏洞安装 TrollStore）
  └─► TrollStore 安装 Dopamine（rootless 越狱，iOS 15.0–16.6.1）
        └─► 安装官方 Arcaea 后运行 AppsDump2.0.7
              └─► 得到已解密的 Arc-mobile.app 完整包（≈940 MB）
```

拿到解密 IPA 后，**放入项目 `input/` 目录即可自动识别**（`*.ipa` 或外层 `*.zip`
暗改包分发格式都行——外层 zip 会自动解出内层 IPA 到 `data/ipa_cache/` 缓存）。
也可以在「配置」中手动填写路径（按文件类型自动判定平台，`.ipa`/`.zip`→iOS）；
「实验」页提供「改用 input/ 自动识别」一键清空配置。

## 三、使用流程

1. 打开「实验」页 → 点「**启用 iOS 模式**」
2. 「解包」页点「扫描」——素材目录秒级建立（17 分类规则与 Android 完全一致，
   只是路径前缀不同）
3. 「替换」页替换素材——操作与 Android 完全相同（头像菱形蒙版、联机立绘半身裁切、
   图片处理管线全部生效）
4. 「替换」页「开始构建」——重打包（原始字节级拷贝）→ 结构校验 → 产出
   **未签名 IPA**（构建时自动移除失效的旧代码签名 `_CodeSignature/`）
5. 下载 IPA，用 **Sideloadly / 爱思助手** 以 Apple ID 签名安装

## 四、签名与安装（用户自理）

- **免费 Apple ID 签名 7 天有效**，到期需重签（重签前先备份存档）
- 每次更新 / 重签前把最新存档上传云端；**24 小时内同一账号登录两台设备会被封禁一段时间**
- 有越狱环境可用 TrollStore 永久签名
- 与官方 App 冲突时可先改 `Info.plist` 的 `CFBundleIdentifier`（本工具暂未提供
  plist 编辑，可在文本替换中自行处理 XML plist）

## 五、能改什么（内容边界）

iOS 包内**没有任何歌曲内容**——音频（567 个 ogg）、谱面（.aff）、曲目背景（307 张）
全部不在包内，运行时下载。因此 iOS 模式只能改：

- ✅ UI 界面（`img/`、`layouts/`）
- ✅ 角色立绘 / 头像（`char/`，含 characters.json 角色名识别）
- ✅ 剧情 CG / 界面（`app-data/story/`、`img/story/`）
- ✅ 启动画面（`startup/`）、音符皮肤（`particle/` + 散件）、模型贴图（`models/`）
- ✅ 字体（`Fonts/`）、文本类素材在线编辑
- ❌ 歌曲音频 / 谱面 / 曲目背景（不在包内）
- ❌ 曲目背景替换需另走「文件共享」把素材注入 App 沙盒下载目录（暗改包做法：
  利用 `UIFileSharingEnabled` + 与 APK 内 `img/bg/1080` 同名的背景素材覆盖）

## 六、常见问题

**Q：扫描提示「不是有效的 IPA」？**
A：包内未找到 `Payload/<App>.app/`。最常见原因是用了**官方 App Store 直装包**
（FairPlay 加密），必须先用越狱 dump 出解密版。

**Q：构建产物装不上？**
A：产物是未签名 IPA，必须先签名：Sideloadly（推荐，免费 ID 7 天重签）或爱思助手
（常需删装，注意 9401 报错与存档备份）。

**Q：切换回 Android 模式后素材还在吗？**
A：在。补丁按 zip 全路径存储，两个平台的补丁互不影响；iOS 补丁（`Payload/...` 路径）
在 Android 构建时会被自动跳过。

**Q：会改坏游戏吗？**
A：工具只替换素材文件，不触碰二进制 / 资源表；但 iOS 包内素材与服务器下发内容
同源，异常素材可能触发检测，请自行评估风险。
