# 说明文档

> 面向普通用户的使用指南。开发者请阅读 [结构原理说明](结构原理说明.md)。
> 使用前请先阅读 [免责声明与注意事项](免责声明与注意事项.md)。

## 这是什么

Arcaea Mod Tool 是一个本地改包工具：把你自己的图片、音频、文本替换进 Arcaea 原版 APK，重新打包签名后生成一个可以安装的 mod APK。

**它能做什么**

- 浏览 APK 内的全部 2D 素材（角色立绘、曲绘、背景、界面、音符皮肤等）
- 用你自己的素材替换任意图片/音频/文本
- 图片智能处理：自动裁切校准、半身裁切、菱形蒙版、缩放、转 JPG
- 重新打包并签名，生成可安装的 mod APK

**它不做什么**

- 不修改任何代码（dex）、不碰底层库（lib）、不改资源表
- 不联网、不上传任何数据
- 不提供任何游戏内功能修改（如解锁、作弊）

## 环境要求

| 项目 | 要求 | 说明 |
|---|---|---|
| 系统 | Windows 10/11 | 其他平台暂不支持（脚本基于 .bat） |
| Python | 3.10+（可选） | `start.bat` 找不到时会提示安装；不装则无法启动 |
| Node.js | 18+（可选） | 仅首次构建前端界面时需要；`dist` 已存在则不需要 |
| 原版 APK | 必须 | 请使用**你自己拥有或有权修改**的游戏副本 |

> 首次运行会自动创建虚拟环境并安装依赖（国内镜像优先），全程无需手动操作。

## 快速开始（三步）

1. **放原包**：把 Arcaea 原版 APK 复制到项目根目录的 `input/` 文件夹（文件名随意，存在多个时取体积最大的）
2. **启动**：双击 `start.bat`，首次运行会自动完成：创建虚拟环境 → 安装依赖 → 构建前端 → 启动服务 → 打开浏览器
3. **扫描**：页面就绪后点击右上角「扫描」，数秒内建立素材目录

## 使用流程

### 一、浏览素材（解包页）

- **左侧分类栏**：全部图片 / 角色立绘 / 曲目背景 / 曲目曲绘 / 音符/轨道皮肤 / 剧情 CG 等 17 个分类，带数量统计
- **搜索框**：按素材路径关键字搜索
- **角色分组**：选择「角色立绘」分类后，素材按角色分组展示（含角色名，来自游戏内 characters.json）
- **排序/分页**：工具栏可切换 路径 / 大小 排序，每页 20~200 张，支持键盘 ←/→ 翻页
- **卡片操作**：点击卡片在右侧详情面板查看；悬停出现勾选框（用于批量导出）

### 二、导出素材

- **单个导出**：详情面板「导出此素材」
- **批量导出**：勾选卡片（可跨页勾选）→ 工具栏「导出选中 N 个」；或直接用「导出全部」导出当前筛选结果
- 导出为 zip 包，保留 APK 内目录结构

### 三、替换素材

1. 点击选中一个素材
2. 把新文件**拖入详情面板的虚线区域**（或点击选择文件）
3. 图片会打开「图片处理对话框」，设置处理选项并实时预览
4. 点击「应用此图片替换」加入替换清单

**图片处理选项详解**

| 选项 | 说明 |
|---|---|
| 自动裁切校准 | **推荐**。按原素材的宽高比裁切并缩放铺满，不变形。可选裁切保留位置：居中 / 顶部（适合立绘头像，保留头部）/ 底部 |
| 保持原始尺寸（拉伸） | 强行拉伸到原素材尺寸（可能变形，一般不推荐） |
| 缩放 % | 按百分比缩放，不做比例适配 |
| 输出格式 | PNG（保留透明）/ JPG（更小，透明变白底） |
| JPG 质量 | 1-100，默认 90 |

**三类素材的自动适配（无需手动设置）**

- **头像**（`assets/char/*_icon.png`）：官方即为"正方形画布 + 菱形镂空"，替换时自动套用菱形蒙版，与官方镂空形状一致；请把主体放在画面中央
- **联机立绘**（`assets/char/*_mp.png`）：官方为半身构图，替换时自动按原图上部约 55% 裁出半身，并在截断处加渐变透明淡出效果（与官方一致）
- **普通立绘/曲绘/背景等**：自动按原素材比例裁切校准

**文本类素材**：详情面板直接在线编辑，保存即生成文本补丁。

### 四、管理替换清单（替换页）

- 左侧清单显示所有已添加的替换项，可**勾选启用/停用**（停用的不参与构建）
- 详情区对比「原素材 vs 替换内容」
- 顶部按钮：**导出包 / 导入**（补丁包 zip，便于分享备份）/ 清空

### 五、构建安装

1. 在替换页点击「开始构建」
2. 等待进度：重打包 → 签名 → 校验（1.8GB 包约 2-4 分钟）
3. 完成后点「下载 APK」
4. **先卸载原版 Arcaea（建议先备份存档），再安装 mod APK**

## 常见问题

**Q：安装提示"缺少开发者证书"/安装失败？**
A：确认卸载了原版 Arcaea（签名不同无法覆盖安装）；确认下载的是构建完成后的 APK 而非 `mod_unsigned.apk`。若仍失败，重新构建一次（签名修复已包含在 1.0 版本中）。

**Q：端口 8000 被占用？**
A：服务已在运行时会自动打开浏览器；或设置环境变量 `AMT_PORT` 换端口（如 `AMT_PORT=8010`）。

**Q：提示"未找到 APK"？**
A：把 APK 放进 `input/` 目录后点「扫描」；或在「配置」弹窗手动填写完整路径。

**Q：缩略图显示白色/空图？**
A：缩略图是浏览器缓存，刷新（Ctrl+F5）即可重新生成。

**Q：构建很久没完成？**
A：1.8GB 的 APK 重打包+签名需要几分钟，属正常；日志窗口会显示当前步骤。

**Q：杀毒软件报毒？**
A：本工具为纯本地 Python 程序，误报时请添加信任；源码完全可见，可自行审查。

**Q：能用其他版本/其他游戏的 APK 吗？**
A：仅支持 Arcaea 2D 素材；版本差异可能导致部分路径无法识别（扫描页可正常浏览即兼容）。

## 数据与备份

- 所有数据保存在 `data/`：补丁内容、缩略图缓存、构建产物、签名密钥
- **建议备份**：`data/patches/`（替换清单）、`data/keystore/`（签名密钥——更换密钥后旧 mod 无法再安装）
- 删除 `data/` 即可完全恢复初始状态（不影响原版 APK）
