## 三、技术风险与注意事项

### 3.1 安装与存档

- mod APK 使用**本地自签名证书**，与官方签名不同：
  - **必须卸载原版后才能安装**（覆盖安装会失败）
  - **卸载会清除本地游戏数据（存档）**。请在卸载前备份存档（Android/data 下的游戏目录，或使用游戏内账号同步）
  - 修改版与官方版不能共存于同一设备（除非系统支持多用户/隔离空间）
- 安装"未知来源应用"需在系统中授权；部分设备/厂商（尤其是国产 ROM）可能拦截非应用商店安装。

### 3.2 版本兼容

- 仅保证对本项目开发时所针对的 APK 版本（6.x）可用；不同版本素材路径可能变化，导致部分素材无法识别或替换后无效果。
- 不同 Android 版本对签名方案的支持不同：本项目输出 v2 签名，Android 7.0+ 均可安装；老旧设备（Android 6 及以下）可能无法安装。

### 3.3 数据安全

- 本项目完全本地运行，**不上传任何数据**；但请勿在不可信网络环境下使用。
- 建议定期备份 `data/` 目录（补丁、密钥、配置）。
- **签名密钥（data/keystore/）就是你的 mod 身份**：删除后生成的 mod 与旧 mod 签名不同，旧 mod 将无法安装/更新。

### 3.4 构建过程

- 构建 1.8GB 级 APK 需要几分钟，期间请勿关闭电脑或中断进程（可能产生损坏的中间文件）。
- 磁盘需保留约 2 倍 APK 大小的空间（原包 + 输出产物）。
- 构建产物请从页面「下载 APK」获取；`data/output/` 下的临时文件可自行清理。

### 3.5 杀毒软件

- 本项目为 Python 脚本 + 本地 Web 服务，部分杀毒软件可能误报；请自行审查源码后再决定是否信任。
- 项目**不包含任何可执行文件**（无 .exe/.dll），所有代码均为可读文本。

### 3.6 已知边界

- 仅支持 2D 素材/音频/文本替换；不修改 dex/lib/资源表，因此无法实现"功能类"修改（解锁、作弊、改判定等）——这是设计使然，降低风险。
- 修改 songlist / characters.json 等数据文件需自行承担风险（可能导致游戏异常）。
- 音频替换为直接替换文件，格式需与原文件一致（如 .ogg），否则游戏可能无法播放。
