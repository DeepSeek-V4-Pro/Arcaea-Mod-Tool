# Arcaea Mod Tool

本地改包工具：直接从 APK 中浏览、替换 **Arcaea** 的 2D 素材（立绘、曲绘、界面、背景、音符皮肤、文本），并重新打包、签名，生成可安装的 mod APK。

> 项目仓库：<https://github.com/DeepSeek-V4-Pro/Arcaea-Mod-Tool>
>
> ⚠️ **使用前请务必阅读 [免责声明与注意事项](docs/免责声明与注意事项.md)**：本工具仅用于个人学习研究；修改、安装 mod APK 可能违反游戏服务条款并导致账号处罚，由此产生的一切后果由使用者自行承担。

## 功能特性

- **低风险改包**：不触碰 dex / lib / 资源表，只替换素材文件
- **极速重打包**：解析 zip 中央目录后做原始字节级拷贝，只重压缩被替换的条目；1.8 GB 的 APK 无需全量解压，分钟级完成
- **智能图片处理**：按素材类型自动适配——按原素材比例裁切校准（可选保留位置）、联机立绘半身裁切 + 底部渐变淡出、头像菱形蒙版、缩放 / 拉伸、PNG / JPG 转换与质量调节
- **素材分类浏览**：17 个分类 + 数量统计；角色分组视图（自动读取 `characters.json` 角色名）；搜索、排序、分页、键盘翻页
- **替换清单管理**：补丁启用 / 停用（停用不参与构建）、补丁包导出 / 导入（zip）、批量勾选导出
- **纯本地运行**：所有数据保存在本机 `data/` 目录，运行时不联网、不上传任何数据
- **自签名**：内置纯 Python 的 APK v2 签名实现，自动生成 / 复用本地密钥
- **开箱即用**：`start.bat` 自动创建虚拟环境、安装依赖、构建前端、识别原包、打开浏览器

## 快速开始

### 环境要求

| 依赖 | 说明 |
| --- | --- |
| Windows | 推荐（启动脚本基于批处理） |
| Python 3.10+ | 必须；安装时勾选 “Add to PATH” |
| Node.js | 可选；仅首次构建前端需要，缺失时后端 API 仍可用 |

### 启动

```bat
:: 1. 把原版 Arcaea APK 放入 input/ 目录（自动识别，无需配置路径）
:: 2. 双击运行
start.bat
```

启动后浏览器自动打开 <http://127.0.0.1:8000>。端口可用环境变量 `AMT_PORT` 覆盖，例如：

```bat
set AMT_PORT=8080
start.bat
```

## 使用流程

1. **放置原包**：把原版 APK 放进 `input/` 目录（存在多个 APK 时按体积取最大者；也可在「配置」弹窗中手动指定路径，手动配置优先）
2. **扫描**：进入「素材浏览」页点击扫描，秒级列出全部 2D 图片素材
3. **替换**：拖拽 / 点击上传你的素材，三栏实时预览（原素材 / 你的素材 / 处理后预览）；文本类素材支持在线编辑
4. **管理清单**：在「替换清单」中查看补丁，可启用 / 停用、导出 / 导入补丁包、批量导出素材
5. **构建**：自动完成 重打包 → 签名 → 三道自校验（内容摘要 / RSA 签名 / 结构解析），进度与日志实时显示，产物在 `data/output/<原包名>_mod.apk`
6. **安装**：⚠️ mod APK 使用本地自签名证书，与官方签名不同，**安装前必须卸载原版**（先备份游戏存档！）

## 界面说明

- **素材浏览（解包页）**：左侧 17 个分类栏 + 数量统计；角色分组视图、搜索、排序、分页
- **素材替换（替换页）**：三栏实时预览、图片处理设置（裁切 / 缩放 / 拉伸 / 转 JPG / 质量）、文本编辑
- **替换清单**：补丁启用 / 停用、补丁包导出 / 导入、批量导出（跨页勾选、全选本页、导出选中 / 全部）
- **构建**：进度 / 日志轮询、产物下载

## 配置

- **端口**：环境变量 `AMT_PORT`（默认 8000）
- **原包路径 / 输出目录**：界面「配置」弹窗中设置，手动配置优先于 `input/` 自动识别
- 所有设置保存在 `data/settings.json`（损坏或缺失时自动回退默认值）

## 常见问题

**Q：端口 8000 被占用？**
`start.bat` 会检测端口占用并直接打开浏览器（说明服务可能已在运行）；或设置 `AMT_PORT` 更换端口。

**Q：安装 mod APK 提示签名不一致 / 安装失败？**
自签名与官方签名不同，必须先卸载原版再安装（注意先备份游戏存档）。

**Q：杀毒软件报毒？**
自签名 APK 可能触发误报；请自行判断来源与风险。本工具完全本地运行，代码均在仓库中，可自行审计。

**Q：前端界面空白 / 样式异常？**
首次运行需要 Node.js 构建前端；若构建失败，可手动执行 `cd webui && npm install && npm run build`。

**Q：游戏更新后分类不准或素材找不到？**
请使用最新原版 APK；游戏版本更新可能改变素材路径，重新扫描即可。

**Q：构建失败？**
查看构建日志：确认至少有一个已启用（勾选）的补丁、原包文件完好、磁盘空间充足。

## 技术实现（简）

- **扫描**：只解析 zip 中央目录（不抽取文件），秒级完成；分类规则按 Arcaea 实际目录结构实测校准
- **重打包**：解析 zip 结构后按偏移顺序字节级拷贝，仅对被替换条目重新压缩
- **签名**：纯 Python 实现 AOSP apksig 算法（算法 ID 0x0103，RSASSA-PKCS1-v1_5 + SHA-256）；密钥自动生成并复用（`data/keystore/`）；构建后本地校验内容摘要与签名，并用官方 apksig 交叉验证结构
- **图片处理**：按素材类型自动识别——头像（`*_icon.png`）套内切菱形蒙版匹配官方镂空形状；联机立绘（`*_mp.png`）半身裁切 + 底部渐变淡出；普通素材按原素材比例裁切校准
