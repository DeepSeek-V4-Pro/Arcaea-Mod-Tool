# 原包放置目录

把 **Arcaea 原版 APK** 直接丢进这个目录即可,工具会自动识别(取体积最大的 `*.apk`),无需手动配置路径。

## 使用方式

```text
input/
├── arcaea_6.16.2c.apk   ← 把原版 APK 放这里(文件名随意,支持任意 *.apk)
└── README.md
```

- 启动后自动使用此目录中的原包;中途放入也无需重启,点「扫描」即生效
- 存在多个 APK 时按文件体积取最大者作为原包
- 也可以在「配置」弹窗中手动填写任意路径,手动配置优先于本目录

## 注意事项

- 请使用你**自己拥有或有权修改**的游戏副本,原包不随本项目分发
- 修改后的 mod APK 输出到 `data/output/`,签名与官方不同,安装前需卸载原版
